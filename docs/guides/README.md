# Staff beta guides

Short, step-by-step guides for the staff who are trying the Church Hub first. Each one is about a
page long. You don't need to read them all: start with **Getting started**, then pick the ones for
the work you do.

| Guide | Who it's for | What it covers |
|---|---|---|
| [Getting started](getting-started.md) | Everyone | Signing in, the Home page, the menu, notifications, getting help |
| [Schedule your team](schedule-your-team.md) | Anyone who schedules volunteers | Volunteer schedule, Who's serving, sending requests, replacements |
| [Take attendance](take-attendance.md) | Anyone who counts on a Sunday | Roll call on a phone, families, new guests, headcounts, "We've missed…" |
| [Media and the app](media-and-the-app.md) | Staff who look after the Sunday videos | The Media library, editing a video, Setup, what members see on Watch |
| [The phone app](the-phone-app.md) | Everyone | The member app, how it differs from the hub, how to tell members to get it |
| [Beta checklist](beta-checklist.md) | Everyone | 15 things to try this week, and how to tell us what felt wrong |

**A few things to know**

- These guides use the names you see on the screen, in **bold**. If a button has a slightly
  different name when you look (we're still polishing), the guide is still right about where it is.
- The hub works on a computer, a tablet and a phone. Most guides say which is easiest.
- Kids' check-in and giving aren't part of this beta. Keep using what you use today.
- Something unclear or wrong in a guide? Tell us on the **Feedback** page. That helps as much as
  telling us about the hub itself.

*For the team that writes these: steps were checked against the screens with made-up demo data.
When a button or page is renamed, update the guide in the same change (see
[design-system.md](../design-system.md#help-guides)).*
