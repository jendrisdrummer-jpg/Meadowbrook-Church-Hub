# Meadowbrook Church: iPhone demo app

A small iPhone app that opens the live member app (`/app/`) inside a native frame. It is for showing church
leadership; nothing on the live site changes. It uses your Mac, Xcode and a **free** Apple ID.

## Put it on your iPhone (first time: about 1 to 2 hours)

1. On your Mac, install **Xcode** from the Mac App Store (it is a big download). Open it once and accept the licence.
2. Install **Node 22 or newer** from nodejs.org (the "LTS" or "Current" installer).
3. On GitHub, open this branch, choose **Code → Download ZIP**, and double-click the ZIP to unzip it.
4. Open **Terminal**, type `cd ` (with a space), drag the unzipped **mobile** folder into the window, press Return.
5. Run `npm install` and wait for it to finish.
6. Run `npm run sync` (the same as `npx cap sync ios`, plus it refreshes the offline page).
7. Run `npx cap open ios`. Xcode opens the project.
8. In Xcode, click **App** (blue icon, top of the left list), then **Signing & Capabilities**. Under **Team** choose
   **Add an Account…**, sign in with your personal Apple ID, then pick "(Personal Team)".
9. If Xcode says the **Bundle Identifier** is taken, change it to something unique, such as
   `church.meadowbrook.hub.demo.yourname`. (The starting value is a placeholder; it lives in
   `church.config.json` and in Xcode. Xcode is the one that counts.)
10. Plug in your iPhone with its cable. Tap **Trust** on the phone and enter your passcode. Choose your iPhone in
    the device menu at the top of Xcode.
11. On the iPhone: **Settings → Privacy & Security → Developer Mode** → turn on, then restart when asked and confirm.
12. In Xcode press the **Run** (play) button. The first build takes a few minutes.
13. When the app is installed but says "Untrusted Developer": on the iPhone go to
    **Settings → General → VPN & Device Management**, tap your Apple ID, tap **Trust**, then open the app.

**Every 7 days** a free Apple ID install expires and the app stops opening. Plug the phone in and press Run in
Xcode again (steps 7 and 12; your data is on the server, nothing is lost).

## What to know when showing it

- **Sign in with an email code or a password.** Google sign-in is hidden inside the app because Google refuses to
  work in an app's built-in browser. It still works on the website.
- Sign-in lasts like the website (30 days). Rarely, if the app is force-closed seconds after signing in, sign in again.
- **No notifications in this demo app.** Notifications still come from the home-screen version of the member app.
- Links to other websites (maps, etc.) open in Safari. If the phone has no connection, the app shows
  "Can't reach Meadowbrook right now" with a **Try again** button.
- The app needs the live site to be awake; the first open after a quiet spell can take a few seconds.

## What is in this folder (for developers)

| Path | What it is |
|---|---|
| `church.config.json` | The one place for per-church values: name, bundle id, hosted URL, colours. |
| `capacitor.config.js` | Reads the file above. Loads the hosted URL; only that host may load in the app. |
| `www/offline.html` | Bundled page shown when the hosted app can't be reached. `church-config.js` next to it is generated by `npm run sync`. |
| `ios/` | The Xcode project (Swift Package Manager; no CocoaPods needed). |
| `assets/logo-white.png` | Meadowbrook's logo (white on transparent). The app icon and launch screen are this logo on a #111111 background. |
| `scripts/make-assets.py` | Optional: redraws the icon and splash from the hub's cross icon. |

Capacitor is pinned to exact versions in `package.json`. `android/` is not added yet (Phase 0 is iPhone only); run
`npx cap add android` later and it will pick up `church.config.json` the same way.
The bundle id and display name are also stored in the Xcode project; if you change them in `church.config.json`,
change them in Xcode too (or delete `ios/` and run `npx cap add ios`).
